# LiveGuard

LiveGuard monitors live pages and streams against a user's goal, preserving observations and the decisions made from them.

## Monitoring memory

**Observation**:
A timestamped OCR, ASR, frame, or visual record from a monitored source. The observation ledger is the source record for what was seen or heard.

**Investigation memory**:
A bounded, expiring note from a completed investigation, tied to a goal version and cited observations. It is a historical retrieval aid, not proof of current state or a standalone alert citation.
_Avoid_: Long-term truth, current event state
