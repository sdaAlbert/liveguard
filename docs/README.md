# LiveGuard 文档导航

LiveGuard 是一个本地直播监控 Agent 项目。若第一次接触代码，请先按下面顺序阅读；如果你只关心一个问题，可直接跳到对应专题。

## 初次阅读路线

1. [项目导览：从目录到一次提醒](PROJECT-GUIDE.md)——先理解项目做什么、代码放在哪里、一次提醒怎样产生，以及状态和错误如何处理。
2. [架构与 Agent 行为](ARCHITECTURE.md)——继续看模块分工、工具权限、证据引用、采样和历史查询的实现细节。
3. [运行、配置与故障处理](OPERATIONS.md)——学习如何启动、配置模型和存储、处理常见故障及备份数据。
4. [评测与验证](EVALUATION.md)——看自动化测试覆盖、历史模型结果、现有吞吐/延迟测量和它们的适用范围。
5. [仍存在的风险](PROJECT-REVIEW.md)——了解当前没有解决的问题和建议的优先顺序。

从仓库根目录开始，还可以阅读 [README](../README.md) 了解功能和快速启动，或 [贡献指南](../CONTRIBUTING.md) 了解开发工作流。

## 如何理解文档中的结论

本文档区分三类陈述：

- **实现事实**：可以在文中链接的 Go 代码或配置里找到对应逻辑。
- **验证结果**：只适用于对应数据集、运行环境和测量路径；历史数字不会自动代表当前代码表现。
- **已知限制/建议**：尚未实现或尚未测量的能力，不应在项目介绍中写成已经完成。

模型输出、队列接收、后端提醒保存、网页推送和用户看到提醒，是不同阶段。阅读性能、可靠性或评测结论时，请确认它说的是哪一个阶段。
