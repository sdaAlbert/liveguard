# 批量巡检压测

LiveGuard 自带可重复的本地负载验收。它会创建一个批次，把多个不同 URL 放入 PostgreSQL 队列，等待有界并发 Worker 完成浏览器证据采集，然后计算端到端延迟和吞吐。

```powershell
go run ./cmd/loadtest -count 12 -timeout 4m
```

2026-09-17 在 Windows、`LIVEGUARD_MAX_CONCURRENT=4`、本地静态直播页条件下的实测结果：

| 指标 | 结果 |
|---|---:|
| 直播间 | 12 |
| 通过 / 需处理 | 12 / 0 |
| 总耗时 | 7.61 s |
| 吞吐 | 1.58 tasks/s |
| P50 / P95 | 4.69 s / 6.99 s |

原始结果见 [`load-test-latest.json`](load-test-latest.json)。这个数字只代表当前机器和本地页面，目的在于证明批次调度、并发上限和统计链路可重复，而不是宣称生产容量。

验收口径固定为页面可访问、处于直播状态，并包含“海边电台”和“互动入口已开启”。任一任务进入异常状态时命令返回非零退出码，因此可放进性能回归流程。
